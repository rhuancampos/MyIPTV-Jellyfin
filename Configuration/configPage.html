Configuração IPTV Xtream

Como configurar:
  1. Preencha Host, Usuário e Senha do seu provedor Xtream Codes ou cole o link da playlist M3U (mais rápido, uma única requisição) e clique em Salvar.
  2. As pastas/arquivo abaixo já vêm com valores padrão — só mude se seu Jellyfin usa caminhos diferentes.
  3. Vá em Painel → Tarefas Agendadas → "Sincronizar MyIPTV" e rode manualmente a primeira vez.
  4. Depois disso, configure o Live TV (M3U Tuner + XMLTV) e as bibliotecas de Filmes/Séries apontando pros caminhos definidos aqui — veja o passo a passo completo no repositório do projeto.
Repositório e documentação: github.com/rhuancampos/MyIPTV-Jellyfin
How to configure:
  1. Fill in Host, Username and Password for your Xtream Codes provider or paste the M3U playlist link (faster, a single request) and click Save.
  2. The folders/file below already have sensible defaults — only change them if your Jellyfin uses different paths.
  3. Go to Dashboard → Scheduled Tasks → "Sincronizar MyIPTV" and run it manually the first time.
  4. Then set up Live TV (M3U Tuner + XMLTV) and your Movie/Series libraries pointing at the paths defined here — see the full walkthrough in the project's repository.
Repository and docs: github.com/rhuancampos/MyIPTV-Jellyfin
Como os arquivos são organizados:
  • Categorias viram pastas, sem o prefixo antes do "|": Filmes | Drama → Drama.
  • Filmes: <Pasta dos Filmes>/Drama/Nome (2019)/Nome (2019).strm
  • Séries: <Pasta das Séries>/Netflix/Nome da Série/Season 01/Nome da Série - S01E09.strm
  • Live TV: um único M3U, com o grupo do canal = categoria (Canais | Globo → Globo) e o guia (EPG) casado por id ou por nome.
  • Nomes são limpos para o Jellyfin achar os metadados: tags como [L] e [4K] saem, Nome - 2009 vira Nome (2009), e : vira -.
  • Título que aparece em mais de uma categoria (ou em mais de uma versão) fica só uma vez, na primeira categoria encontrada; versões legendadas [L] só entram se não houver outra.
  • Arquivos só são regravados quando mudam. O plugin nunca apaga nada.
How files are organized:
  • Categories become folders, without the prefix before the "|": Filmes | Drama → Drama.
  • Movies: <Movies folder>/Drama/Name (2019)/Name (2019).strm
  • Series: <Series folder>/Netflix/Show Name/Season 01/Show Name - S01E09.strm
  • Live TV: a single M3U, channel group = category (Canais | Globo → Globo) and the guide (EPG) matched by id or by name.
  • Names are cleaned so Jellyfin finds metadata: tags like [L] and [4K] are dropped, Name - 2009 becomes Name (2009), and : becomes -.
  • A title present in more than one category (or version) is written once, in the first category found; subtitled [L] versions are only used when there is no other.
  • Files are only rewritten when they change. The plugin never deletes anything.

Fonte dos dados

Ex: http://dns:porta/get.php?username=...&password=...&type=m3u_plus&output=ts. Se preenchido, a sincronização baixa essa playlist (uma única requisição, com categorias e episódios) e ignora Host/Usuário/Senha abaixo. O parâmetro output (ts ou m3u8) define o formato dos canais ao vivo. Deixe em branco para usar a API Xtream. / If set, sync uses this playlist and ignores Host/Username/Password below.
Ex: http://meu-dns.com:8080 (Inclua http:// e a porta)

Sincronização (Live TV / Filmes / Séries)

Caminho dentro do container, ex: /data/movies
Caminho dentro do container, ex: /data/tvshows
Caminho do arquivo gerado, ex: /config/live-tv.m3u (use esse mesmo caminho ao criar o M3U Tuner em Live TV)
A sincronização roda como tarefa agendada do Jellyfin (Painel → Tarefas Agendadas → "Sincronizar MyIPTV"), com execução diária às 04:00. Rode manualmente por lá quando quiser atualizar agora.
